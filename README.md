# Portfólio profissional

## Sobre o projeto
Este é o portfólio profissional de **Caio Araujo**, estudante de Análise e Desenvolvimento de Sistemas
na Universidade Cruzeiro do Sul. O projeto foi desenvolvido como atividade da disciplina **Design
Profissional**, com o objetivo de apresentar minha formação, competências e projetos práticos
realizados durante o curso.

## Objetivos
- Praticar HTML5 semântico e CSS3 puro (sem frameworks).
- Organizar e apresentar minhas competências técnicas e comportamentais.
- Divulgar projetos reais desenvolvidos durante a faculdade.
- Publicar um site funcional e responsivo utilizando o GitHub Pages.

## Tecnologias utilizadas
- HTML5
- CSS3 (Flexbox)
- Git e GitHub
- GitHub Pages (hospedagem)

## Projetos apresentados

### Fast Track
Sistema de fila de atendimento desenvolvido em Python, como parte da disciplina de Fundamentos de
Python. Implementa cadastro de chamados, priorização, fila FIFO e tratamento de erros.
🔗 [Ver repositório](https://github.com/araujoc-dev/FUNDAMENTOS-PYTHON/tree/main/ads-1semestre-exercicios-python/Projeto%20Fast%20Track)

### Arena Tech
Calculadora de custos para eventos de e-sports, desenvolvida em C, como parte da disciplina de
Fundamentos de Linguagem C. Calcula número de times, consumo de energia, custo de alimentação e
custo total do evento.
🔗 [Ver repositório](https://github.com/araujoc-dev/FUNDAMENTOS-LINGUAGEM-C/tree/main/Linguagem%20C/Projeto%20Arena%20Tech)
